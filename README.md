# Planet Facts Website

This project is a static website that provides interesting facts about the planets in our solar system. It includes various resources such as images, styles, and data files to enhance the user experience.

## Project Structure

- **index.html**: The main landing page of the website.
- **css/**: Contains all the stylesheets used to style the website.
- **js/**: Includes all the JavaScript files used for interactivity and functionality.
- **assets/**: Contains images and other media files used throughout the website.
- **data/**: Includes any data files (e.g., JSON or CSV) that are used to display information dynamically.
- **fonts/**: Fonts used on the website to enhance typography.
- **.git/**: Version control data managed by Git.
- **.gitignore**: Specifies files and directories to be ignored by Git.

## Installation

To run this website locally, you don't need any special installation. Simply clone this repository and open the `index.html` file in your browser:

```bash
git clone <your-repository-url>
cd planetfacts
open index.html
